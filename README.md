# Robotic Hands

---

## About the Project

This is a robotic hand project developed using **Arduino and C++**, with its movements controlled through buttons.

The project combines **electronics, programming, mechanical assembly, and 3D-printed components** to create a functional robotic hand capable of performing programmed movements based on user input.

The project was collaboratively developed by the members of **CHEB-Labs**, a group of students from ETEC ZL, as a practical application of programming and hardware concepts.

---

## Objectives

The main objectives of the project are:

* Develop a functional robotic hand using Arduino.
* Control the hand's movements through physical buttons.
* Apply C++ programming to an embedded system.
* Integrate electronic and mechanical components.
* Design and assemble the physical structure of the hand.
* Explore the integration between software and hardware.
* Document the development process and technical decisions.

---

## How It Works

The robotic hand receives commands through **buttons** connected to the Arduino.

The Arduino processes these inputs through a program developed in C++ and sends the corresponding commands to the components responsible for the hand's movements.

The project can be divided into three main layers:

```text
┌─────────────────┐
│     Buttons     │
│    User Input   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│     Arduino     │
│  C++ Processing  │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  Robotic Hand   │
│    Movement     │
└─────────────────┘
```

## Hardware

The project uses a combination of electronic and mechanical components, including:

* Arduino board
* Buttons
* Servo motors
* Connecting wires
* Power supply
* 3D-printed structural components

> The complete list of components and their technical specifications will be presented in the project's technical documentation.

---

## 3D-Printed Components

The physical structure of the robotic hand is made of 3D-printed components, including the **forearm, palm, fingers, controller, and base**, designed to support the mechanical movement of the fingers and other parts of the system.

The corresponding models and manufacturing information will be added to the repository as the project documentation is completed.

---

## Software

The robotic hand is programmed in **C++ using the Arduino IDE**.

The software is responsible for:

* Reading button inputs.
* Processing user commands.
* Controlling the hand's movements.
* Managing the interaction between the inputs and hardware components.

The source code will be available in this repository.
